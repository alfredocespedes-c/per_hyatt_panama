# Hyatt Regency Panama City · Welcome intro + survey (demo)

Static page: 3D aerial intro (Three.js) toward the hotel, transition into the ballroom, then a 4-question survey.
Demo: answers are stored in the browser (localStorage). `?admin=1` shows responses and CSV export; `?form=1` skips the intro.
Run locally: `python -m http.server 8000` and open http://localhost:8000.
